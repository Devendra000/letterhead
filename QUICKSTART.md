# Quick Start Guide

## Installation & Running

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start the development server:**
   ```bash
   npm run dev
   ```

3. **Open in browser:**
   Navigate to `http://localhost:3000`

## First Time Use

1. Enter your company information (name, address, phone, email)
2. Click "Start Writing"
3. Click anywhere on the document to add text
4. Click on text to select and format it using the toolbar
5. Your document and letterhead auto-save

## Key Features

- **Free-form editing** - Click anywhere to add text boxes
- **Drag & position** - Position text anywhere on the page
- **Text formatting** - Font selection, size, bold, italic, underline
- **Auto-save** - Everything saves automatically to your browser
- **Print ready** - Prints on standard 8.5" x 11" letter size
- **Edit letterhead** - Change letterhead info anytime with the Edit Letterhead button

## Build for Production

```bash
npm run build
npm start
```

Enjoy your letterhead editor!
